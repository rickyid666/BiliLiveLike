# BiliLiveLike - B站直播自动点赞

纯接口实现的 B 站直播间自动点赞工具：**不弹任何窗口、不模拟鼠标**。
登录走官方扫码接口，点赞走官方直播间点赞接口（与手动双击点赞同一接口）。

## 使用方法

1. 双击运行 `BiliLiveLike.exe`（或 `python bili_like_api.py`）
2. 输入 `login` 回车 —— 终端会显示二维码，用 **哔哩哔哩手机App** 扫码确认
   （也可以输入 `paste`，把浏览器里的 Cookie 请求头直接粘贴进来登录）
3. 输入 `go 6`（换成你要点赞的房间号，或直接粘直播间链接）开始点赞
4. `stop` 停止 / `status` 查看进度 / `quit` 退出

- 登录信息保存在 exe 同目录的 `cookies.json`，下次启动免登录
- 点赞节奏：随机间隔 5~8 秒，每次连击 10~20 赞，单场上限 1000 赞（可在 `config_api.json` 调整）
- 触发风控（-352）会自动放慢速度；登录失效（-101）会提示重新扫码
- 点赞仅在主播开播时有效；单场直播点赞获取上限约 1000

## GitHub Actions 自动构建 exe

1. 把本目录内容推送/上传到你的 GitHub 仓库（注意 `.github` 是隐藏文件夹，必须一起传）
2. 两种方式出包：
   - **手动**：仓库页 → Actions → Build EXE → Run workflow，完成后在 Artifacts 下载 `BiliLiveLike-windows-x64`
   - **发版**：推一个 `v` 开头的 tag（如 `v1.0.0`），自动构建并创建 Release 附带 exe
3. 无需本地安装 Python

## 注意事项

- Cookie 等同于账号密码，`cookies.json` 不要泄露或上传到仓库（已默认不会被提交，若误传请立即在B站改密码/下线设备）
- 自动化点赞属于灰色地带，已按真人节奏随机化，请勿调激进参数
