# BiliLiveLike

B站直播间自动点赞。纯接口实现，不开浏览器，也不模拟鼠标。

登录用官方扫码接口，终端里直接出二维码，手机B站App扫一下就行；嫌扫码麻烦也可以直接贴浏览器的 Cookie。点赞走的接口和你手动双击屏幕点赞是同一个。

## 用法

双击 `BiliLiveLike.exe`（或 `python bili_like_api.py`）：

```
login        终端出二维码，手机扫码确认
paste        直接粘贴浏览器里的 Cookie 请求头内容
go 6         给 6 号房间点赞，房间号可以换成任意房间，也能粘完整链接
stop         停止
status       看进度
quit         退出
```

Cookie 存在同目录 `cookies.json`，下次打开不用重新登录。

节奏是随机的，5~8 秒一次，每次算 10~20 个赞，单场最多 1000——差不多就是官方点赞任务的上限。主播没开播的话点了也白点，程序会提示你。

想改参数的话，同目录 `config_api.json`，间隔和上限都在里面。

## 自己打包

仓库带了 GitHub Actions 配置。Actions 页面手动 Run workflow 就能出 exe；或者推一个 `v` 开头的 tag，会自动构建并发 Release。

## 几句提醒

`cookies.json` 等于账号本体，别发给别人，也别提交到仓库（.gitignore 已经挡了）。

自动点赞本质是脚本调接口，频率我按真人习惯做了随机化，别去调太快。

## 常见报错

- `code=-352`：触发风控了，程序会自己放慢速度，等一会儿重试
- `code=-101`：登录过期，重新 `login` 一下
