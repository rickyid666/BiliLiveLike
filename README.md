# BiliLiveLike

B站直播间自动点赞。纯接口实现，不开浏览器自动化，也不模拟鼠标。

登录用官方扫码接口，手机B站App扫一下就行；嫌扫码麻烦也可以直接贴浏览器的 Cookie。点赞走的接口和你手动双击屏幕点赞是同一个。

三个客户端 + 一个手机 App，功能完全一样，挑顺手的用：

| 版本 | 文件 | 说明 |
|---|---|---|
| 图形界面 | `BiliLiveLike.exe` | 原生窗口，双击打开。扫码弹窗显示二维码，参数直接在窗口里调 |
| 网页界面 | `BiliLiveLike-web.exe` | 本地起个服务，浏览器打开即用；加 `--lan` 手机同 WiFi 也能访问 |
| 命令行 | `BiliLiveLike-cli.exe` | 终端里 `login` / `go 房间号`，给喜欢敲命令的 |
| 手机 App | `BiliLiveLike.apk` | 安卓手机直接装，应用内登录（不用扫码、不用复制 Cookie） |

## 用法

**手机 App（Android 8.0 以上）**：安装 APK → 打开 → 右上角「登录哔哩哔哩」在应用内完成登录 → 填房间号 → 开始点赞。
装的时候系统可能提示「未知来源」，允许一次就行。

手机版的特点：
- **应用内登录**：点「登录哔哩哔哩」，在 App 里用账号密码 / 短信验证码登录，不用扫码、不用复制 Cookie
- **息屏也能跑**：任务运行时会挂一个常驻通知（前台服务），切后台、锁屏都不会断
- **自动等开播**：主播没开播就每分钟检查一次，开播了自动开始点（参数里可关）

**图形界面版**：双击打开 → 右上角「扫码登录」→ 填房间号 → 「开始点赞」。

右上角还有个「深色 / 浅色」按钮，切换主题是平滑过渡，选择会记住。

**网页界面版**：双击 `BiliLiveLike-web.exe`，会自动打开 http://127.0.0.1:8848 。
想让手机也能用，命令行加参数：`BiliLiveLike-web.exe --lan`，然后用手机浏览器访问终端里显示的局域网地址（手机和电脑要连同一个 WiFi）。

网页版右上角也有主题按钮，循环切换「跟随系统 / 浅色 / 深色」。

**命令行版**：

```
login        终端出二维码，手机扫码确认
paste        直接粘贴浏览器里的 Cookie 请求头内容
go 6         给 6 号房间点赞，房间号可以换成任意房间，也能粘完整链接
stop         停止
status       看进度
quit         退出
```

三个版本登录信息通用，都存同目录 `cookies.json`，登录一次以后免登录。

节奏是随机的，5~8 秒一次，每次算 10~20 个赞，单场最多 1000——差不多就是官方点赞任务的上限。主播没开播的话点了也白点，程序会提示你。

### 关于签名

仓库里没配签名密钥时，APK 用调试签名打包，**每个版本签名都不同**，装新版得先卸载旧版。
想让它像正常 App 一样直接覆盖升级（保留登录态和参数），在仓库 Secrets 里配 4 个值即可，
配好后构建日志会显示「使用固定签名构建 release 包」：
`ANDROID_KEYSTORE_BASE64` / `ANDROID_KEYSTORE_PASSWORD` / `ANDROID_KEY_ALIAS` / `ANDROID_KEY_PASSWORD`

## 自己打包

仓库带了 GitHub Actions 配置。Actions 页面手动 Run workflow 就能出三个 exe；或者推一个 `v` 开头的 tag，会自动构建并发 Release。

## 几句提醒

`cookies.json` 等于账号本体，别发给别人，也别提交到仓库（.gitignore 已经挡了）。

网页版服务默认只监听本机；用了 `--lan` 之后同网段的设备都能打开这个页面——公共 WiFi 下别开。

自动点赞本质是脚本调接口，频率我按真人习惯做了随机化，别去调太快。

## 常见报错

- `code=-352`：触发风控了，程序会自己放慢速度，等一会儿重试
- `code=-101`：登录过期，重新扫码登录一下
